# Estructuras I: método de rigidez

Libro, banco de comprobación y hoja de cálculo integrada. Sitio estático en español.

## Entradas

- `index.html`: libro y presentación.
- `banco.html`: ejercicios con hoja libre integrada.
- `calculadora.html`: calculadora matricial independiente.
- `assets/downloads/`: plantillas, cuadernos y soluciones didácticas.

## GitHub Pages

Publique el contenido de esta carpeta en la raíz del repositorio. En **Settings → Pages**, elija **Deploy from a branch**, rama principal y **/(root)**. Conserve `.nojekyll`. No requiere compilación ni dependencias instaladas.

## Prueba local opcional

Sirva esta carpeta por HTTP, por ejemplo con `python -m http.server 8000`, y abra `http://localhost:8000/`. No use doble clic en el HTML: los módulos JavaScript necesitan un servidor HTTP.

## Alcance

Curso de análisis matricial lineal elástico y pequeños desplazamientos. Las comprobaciones didácticas no sustituyen la revisión de un modelo estructural real. Las soluciones son públicas. El trabajo del estudiante se guarda en su navegador, no en un servidor docente. Cambiar de dominio no traslada automáticamente el almacenamiento anterior.
